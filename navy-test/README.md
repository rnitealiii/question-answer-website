# Pak Navy Civilian Apprenticeship — Test Preparation

A simple practice-test website for the Pakistan Navy Civilian Apprenticeship entry test (matric-based), built in the Pak Navy E-Testing pattern.

## Tests included

| Test | Questions | Time |
| --- | --- | --- |
| Verbal Intelligence | 75 MCQs | 45 minutes |
| Non-Verbal Intelligence | 60 MCQs | 45 minutes |
| Academic (English, Maths, Physics, Chemistry, GK) | 75 MCQs | 45 minutes |

Passing marks: 50%. Total: 210 original practice MCQs written in the Navy test pattern.

## How to use

Open `index.html` in any browser (phone or computer). Select a test, answer the questions before the timer ends, and submit to see your score — correct, wrong and skipped counts, PASS/FAIL result, and a full review of every question with the correct answers.
